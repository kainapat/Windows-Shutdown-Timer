# บันทึกรายงานการวิเคราะห์ข้อผิดพลาดและปรับปรุงสถาปัตยกรรม (Post-Mortem): ระบบเลือกเวลาแบบกดเลือก (Dropdown Time Selectors)

## 1. สรุปภาพรวม (Summary)
ในแอปพลิเคชัน Windows Shutdown Timer v2.2.0 การตั้งเวลาทั้งใน **Timer Mode (นับถอยหลัง)** และ **Clock Mode (ระบุเวลาจริง)** เคยใช้คอนโทรลแบบช่องพิมพ์ตัวหนังสือ (`QSpinBox` และ `QDateTimeEdit`) ซึ่งบังคับให้ผู้ใช้ต้องคลิกพิมพ์ตัวเลขเองผ่านแป้นพิมพ์ ไม่สามารถคลิกเลือกจากรายการได้สะดวก จึงได้ดำเนินการรีแฟกทอริงโดยเปลี่ยนคอนโทรลทั้งหมดเป็นเมนูดรอปดาวน์ (`QComboBox` สำหรับ ชั่วโมง, นาที, วินาที) และปฏิทินป๊อปอัป (`QDateEdit`) จัดเรียงแบบ 3 คอลัมน์สมมาตร พร้อมสร้าง Adapter Proxies (`SpinBoxProxy`, `DateTimeProxy`) เพื่อรองรับการทำงานย้อนหลัง 100%

## 2. อาการที่พบ (Symptom)
- ในโหมด **Clock (ระบุเวลาจริง)**: เมื่อกดปุ่มปฏิทินในช่อง `self.date_edit` ผู้ใช้สามารถจิ้มเลือกได้เฉพาะ "วันที่" เท่านั้น ส่วน "ชั่วโมงและนาที" ผู้ใช้จำเป็นต้องคลิกเข้าไปในช่องข้อความแล้วกดแป้นพิมพ์ตัวเลขเอง
- ในโหมด **Timer (นับถอยหลัง)**: ช่องชั่วโมง นาที และวินาที เดิมเป็น `QSpinBox` ที่ผู้ใช้ต้องพิมพ์ หรือต้องคอยเล็งกดปุ่มลูกศรขึ้น/ลงขนาดเล็ก ทำให้การใช้งานบนเดสก์ท็อปไม่สะดวก

## 3. สาเหตุที่แท้จริง (Root Cause)
1. **การเลือกคอนโทรลที่ไม่ตรงกับพฤติกรรมผู้ใช้**: ในการปรับปรุงเวอร์ชันก่อนหน้า มีการเลือกใช้ `QSpinBox` และ `QDateTimeEdit` เพราะขนาดกะทัดรัด แต่ไม่ได้คำนึงว่าผู้ใช้เดสก์ท็อปส่วนใหญ่ต้องการใช้เมาส์คลิกเลือกเวลามากกว่าการพิมพ์
2. **ข้อจำกัดของ QDateTimeEdit ใน Qt**: คอนโทรล `QDateTimeEdit` ของ Qt มีปฏิทินป๊อปอัปให้เฉพาะส่วนของวันที่ แต่ไม่มี UI วงล้อหรือเมนูดรอปดาวน์สำหรับเลือกเวลา (HH:mm) ในตัว
3. **ความไม่สมมาตรของเลย์เอาต์เดิม**: โหมด Clock เดิมวางเป็นแถวแนวนอนยาวช่องเดียว ขณะที่โหมด Timer วางเป็น 3 คอลัมน์ ส่งผลให้เมื่อมีการเลื่อนสลับโหมดด้วย `SlidingStackedWidget` เลย์เอาต์เกิดการขยับและไม่กลมกลืน

## 4. กลไกที่ทำให้เกิดปัญหา (Why it produced the symptom)
`QDateTimeEdit` ทางสถาปัตยกรรมคือ text field ที่ครอบด้วย spin buttons ผู้ใช้ที่ต้องการตั้งเวลาเป้าหมายจึงต้องใช้คีย์บอร์ดพิมพ์ตัวเลขทีละหลัก ทำให้เสียเวลาและขัดกับความต้องการใช้งานแบบด่วน

## 5. การแก้ไข (Fix)
1. **เลย์เอาต์ 3 คอลัมน์สมมาตรแบบดรอปดาวน์**:
   - **โหมด Timer**: เปลี่ยนเป็น 3 เมนูดรอปดาวน์:
     - `self.hours_combo`: `0 hr` ถึง `24 hr` (25 ตัวเลือก)
     - `self.minutes_combo`: `0 min` ถึง `59 min` (60 ตัวเลือก)
     - `self.seconds_combo`: `0 sec` ถึง `59 sec` (60 ตัวเลือก)
   - **โหมด Clock**: เปลี่ยนเป็น 3 คอลัมน์ที่สมมาตรกัน:
     - `self.date_picker`: `QDateEdit` พร้อมปฏิทินป๊อปอัป ฟอร์แมต `"ddd d MMM yyyy"`
     - `self.time_hours_combo`: `QComboBox` เลือก `00` ถึง `23` (24 ตัวเลือก)
     - `self.time_minutes_combo`: `QComboBox` เลือก `00` ถึง `59` (60 ตัวเลือก)
2. **Proxy Adapters เพื่อความเข้ากันได้ย้อนหลัง**:
   - สร้างคลาส [`SpinBoxProxy`](file:///d:/Windows%20Shutdown%20Timer/shutdown_timer.py) เพื่อให้โค้ดส่วนอื่นที่เรียก `.value()` และ `.setValue()` ยังทำงานได้ตามปกติ
   - สร้างคลาส [`DateTimeProxy`](file:///d:/Windows%20Shutdown%20Timer/shutdown_timer.py) เพื่อให้โค้ดที่เรียก `.dateTime()`, `.date()`, `.time()`, และ `.setDateTime()` ยังทำงานได้สมบูรณ์
3. **การซิงก์ Preset และค่าเริ่มต้น**:
   - ปรับ `apply_preset()` ให้สลับมาหน้า Timer และซิงก์ค่าเวลาลงดรอปดาวน์ทันที
   - กำหนดค่าเริ่มต้นของ Clock เป็น `เวลาปัจจุบัน + 1 ชั่วโมง` เพื่อป้องกันการแจ้งเตือนว่าเวลาเป็นอดีต
4. **ปรับปรุง Stylesheet QSS**:
   - เพิ่มสไตล์สำหรับ `QDateEdit` และเพิ่ม Custom Scrollbar ให้กับลิสต์ดรอปดาวน์ในทั้ง Dark Mode และ Light Mode
