# Linear and Raycast-Style Precision Utility Redesign

Replaced the emoji-heavy instructional bento box layout and parenthetical dual-language text with a refined Linear/Raycast-inspired precision utility interface. Emojis in labels are replaced with clean monochrome vector SVG icons (Power, Restart, Moon, Hibernate) and desaturated semantic action accents. Added dedicated dynamic language switching (EN / TH) in the header to eliminate parenthetical text noise. Replaced mode radio buttons with a segmented pill control, refined time inputs and preset chips, introduced a slim micro-progress indicator with precision chronometer display, and constrained content to a centered maximum width container (~620px) to maintain elegant proportions across expanded window resolutions. All existing timing, scheduling, and system execution functionality remains strictly unchanged.
