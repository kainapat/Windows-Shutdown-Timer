Windows Shutdown Timer Architecture

A 3-tier desktop application architecture featuring a 3-Step Vertical Bento UI, central state orchestration with QTimer precision, and atomic persistence interacting with Windows native subsystems.

PRESENTATION LAYER

3-Step Vertical Bento UI

Crafted with PySide6 widgets following a streamlined 3-Step vertical flow: Action selection pills, time duration spinbox/clock picker, and execution trigger controls.

  • Hero countdown card with smooth progress bar
  • BentoCard glass containers & animated buttons
  • Cinematic floating toast notification overlay

ORCHESTRATION LAYER

Central App Controller

ShutdownTimerApp orchestrates all component lifecycles, signal dispatching, validation boundaries (e.g. 72h max safety check), and 1-second cadence timer ticks.

  • Atomic state machine tracking active timers
  • Dynamic theme generator (Dark / Light / Action Accents)
  • Graceful signal trapping (SIGINT / SIGBREAK)

SYSTEM & STORAGE

Windows Subsystem & JSON

Direct integration with native Windows executables and safe transactional file writes to maintain configuration consistency.

  • shutdown.exe (/s, /r, /a) & powrprof.dll via rundll32
  • Atomic file persistence (.tmp rename replacement)
  • Cross-session window geometry & state recovery
