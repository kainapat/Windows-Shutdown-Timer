Payload Data Flow & State Pipeline

End-to-end trace of timing parameters, validation transformations, countdown progress streaming, and Windows subsystem execution across 4 architectural roles.

INPUT TO STATE

Capture & Validation

User selections in SpinBoxes or PresetCards are converted to structured datetime target timestamps, guarded by delta checks and confirmation prompts.

PRECISION TICKING

Countdown & Progress

Active timers tick every 1000ms via QTimer, computing remaining seconds and percentage chunks to update the Hero countdown display.

FINAL DISPATCH

System Level Execution

Upon timer expiration or immediate triggers, final power states (shutdown / restart / sleep / hibernate) are dispatched directly to the Windows kernel.
